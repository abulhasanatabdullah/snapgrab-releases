কীভাবে install করবেন

  1. উপরের ডাউনলোড করুন বোতামে চাপ দিন। SnapGrab.apk নামের ফাইলটা নামবে।
  2. নামা শেষ হলে ফাইলটা খুলুন। ফোন অনুমতি চাইলে "এই উৎস থেকে অনুমতি দিন" চালু করে ফিরে আসুন।
  3. Install চাপুন। ব্যস, অ্যাপ তৈরি। পরের আপডেটগুলো অ্যাপ নিজেই জানাবে।
বোতামের ফাইল install না হলে (পুরনো ফোন)

খুব পুরনো কিছু ফোনে (সাধারণত ২০১৭-এর আগের) "অ্যাপটি install হয়নি" দেখাতে পারে। তখন এটা নিন:

  • পুরনো ফোনের জন্য (৩২-বিট)
  • কম্পিউটারের এমুলেটর বা Chromebook-এর জন্য
এটা কি নিরাপদ?

প্রতিটা ভার্সন একই চাবি দিয়ে সই করা, যাতে কেউ বদলে দিলে ধরা পড়ে। সেই চাবির SHA-256 ছাপ:

70:0F:C1:86:64:48:9C:F2:74:1E:39:92:7C:CE:BE:1B:6E:75:F1:BD:54:6B:24:22:DD:92:5A:D2:DC:4E:85:07

অ্যাপটা কোনো লিংক বা ব্যক্তিগত তথ্য সংগ্রহ করে না। পুরো সোর্স কোড প্রকাশিত (GPL-3.0)।

এটা Play Store-এ নেই কেন?

Play Store ভিডিও ডাউনলোডের অ্যাপ রাখে না। তাই অ্যাপটা সরাসরি এখান থেকে দেওয়া হয়, আর অ্যাপ নিজেই নতুন ভার্সনের খবর দেয়।
